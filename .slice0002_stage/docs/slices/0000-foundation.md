# Slice 0000 — foundation

## Outcome

Create the src-layout Python package, architecture boundaries, minimal importable version, help/version-only CLI, focused smoke test, baseline history contract, and handoffs for Slices 0001 and 0002. Initialize and publish the private repository.

## Explicit exclusions

No option-skew calculation, statistical estimator, cloud reader/writer, scheduler, report result, fabricated market data, or recurring job is implemented. The example configuration documents future inputs and outputs only.

## Acceptance

- Editable install succeeds on Python 3.11 or newer.
- Package import and CLI help/version work.
- The focused smoke test passes.
- The documented layers and history contract agree.
- Only intended foundation content is committed and the private remote is verified.
